# Numbers and tables of the paper

These files are the numbers exactly as printed in the paper, so each one can be found by search.

- `NUMBERS.md`: every number macro of the paper with its value, a description and the file it is computed from.
- `numbers.tex`: the same values as LaTeX macros, as the paper loads them.
- `table_*.tex`: the paper's tables as generated by `analysis/paper_tables_v2.py` (Table 1 `table_results`, Table 2 `table_hparams`, Table 3 `table_deviations`, Table 4 `table_runs`, Table 5 `table_runs_all`, Table 6 `table_loo`, Table 7 `table_checks`).
- `table5_every_run.csv`, `table6_leave_one_draw_out.csv`: Tables 5 and 6 as CSV.

Every value traces back to `evaluation/` and `results_corrected/`; `python analysis/recompute_from_results.py` recomputes 55 of them from those files and checks them against the paper.
